# Dimensional Resources Guide Book

## Dimensional Resources

Dimensional Resources is a mod that allows you to discover planets and mine resources from them using a Laser!

## Getting Started

Firstly in the world you will find a new ore called Dimensional Ore, this is found very low in the world between -16 and -64. Mining this ore will give you Dimensional Shards, a core ingredient for the mod
<Row>
    <BlockImage id="dimresources:deepslate_dimensional_ore" scale="4" />
    <BlockImage id="dimresources:dimensional_ore" scale="4" />
</Row>

Next you will need to craft yourself a Spyglass and a Planet Locator
<Row>
    <Recipe id="minecraft:spyglass" />
    <Recipe id="dimresources:planet_locator" />
</Row>
Whilst holding a Planet Locator in your offhand and using a Spyglass look into the sky to find planets!. After discovering a Planet the Planet Locator will be set to that Planet
